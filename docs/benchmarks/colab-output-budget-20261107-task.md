Implement a durable, concurrent SQLite job queue in one Python 3 standard-library-only file. Return exactly one fenced Python code block, with no text outside it. Do not output tests, a CLI, or a demonstration. This is a correctness task, not a request to maximize response length. Work through transactional races and boundary conditions before producing the implementation.

Expose class JobQueue(path). Each operation must be atomic, persist across independent processes/restarts, and be safe when the same instance is used concurrently by threads. Use a file-backed SQLite database, WAL mode, a busy timeout and committed transactions; no Python-only lock can serve as the cross-process correctness mechanism. Do not rely on background workers or wall-clock time: methods receive an explicit finite numeric now. Return fresh decoded JSON objects, not mutable references to internal state.

Methods and semantics:

1. enqueue(key, payload, *, priority=0, run_at=0.0, max_attempts=3, depends_on=()) -> bool. A new key inserts a waiting job with attempts=0. An existing key returns False and must not modify any of its fields, including payload or dependencies. key must be a nonempty string; priority must be an int other than bool; max_attempts must be a positive int other than bool. run_at must be finite numeric other than bool, and may be negative. payload must be JSON serializable with NaN/Infinity forbidden; invalid input raises ValueError. Dependencies are existing job keys; reject unknown dependencies or self-dependency with ValueError. Deduplicate dependency keys. JSON null is allowed as a payload.

2. set_dependencies(key, depends_on) -> bool. Replace dependencies only while that job is waiting and has attempts=0; otherwise return False, including for an unknown job. Reject unknown dependency keys, self-dependency and any transitive cycle with ValueError. A rejected update leaves all previous dependency edges intact. Deduplicate keys. This operation must serialize correctly with claiming and other graph edits.

3. claim(worker, *, now, lease_seconds) -> dict | None. worker is a nonempty string, now is finite numeric other than bool, and lease_seconds is positive finite numeric other than bool; invalid inputs raise ValueError. In a single write transaction, first expire all running leases whose lease_until <= now. An expired job with attempts >= max_attempts becomes failed; otherwise it becomes waiting with run_at=now. Clear expired ownership/token/lease. Next transitively mark every waiting job having a failed/cancelled dependency as failed, without consuming an attempt. Then select one waiting job with run_at <= now and ALL dependencies succeeded. Order eligible jobs by priority descending, run_at ascending, key ascending. Set it running, increment attempts by exactly one, assign worker, lease_until=now+lease_seconds, and a fresh unpredictable fencing token. Return a dict containing key, payload, worker, token, attempt, lease_until. Return None when no job is eligible. Concurrent processes/threads must never obtain the same active lease; two jobs can be claimed independently.

4. heartbeat(key, token, *, now, lease_seconds) -> bool. Validate time/duration as above. Only a matching running token with now < lease_until is authorized. On success set lease_until=max(old lease_until, now+lease_seconds); attempts and token do not change. Expired, stale, cancelled, terminal or unknown tokens return False. The exact expiry instant is already expired.

5. ack(key, token, *, now, result=None) -> bool. Validate now and JSON result (including rejection of nonfinite JSON) with ValueError for invalid input. Only a matching running token with now < lease_until can succeed. Set status=succeeded, persist decoded result, and clear worker/token/lease_until. Return False for unauthorized tokens; a late worker must never overwrite a newer worker's state. A second identical ack returns False.

6. fail(key, token, *, now, error, retry_delay=0.0) -> bool. now must be finite, error must be a string, retry_delay must be nonnegative finite numeric, all bool time values are invalid; invalid input raises ValueError. Only a matching unexpired running lease can be failed. Persist error. If attempts >= max_attempts set failed, otherwise return to waiting with run_at=now+retry_delay. Clear worker/token/lease_until; never increment attempts here. Return False for unauthorized tokens.

7. cancel(key) -> bool. Waiting/running jobs become cancelled with ownership/token/lease cleared. Unknown or already-terminal jobs return False. Cancellation fences an in-flight worker immediately. Descendant failure propagation is performed at the next claim.

8. get(key) -> dict | None. Return None if absent. A job dict must contain key, payload, status, attempts, max_attempts, priority, run_at, worker, token, lease_until, result, error, depends_on (a sorted list). statuses are waiting/running/succeeded/failed/cancelled. Unset worker/token/lease_until/result/error fields are None. get does not itself expire leases or propagate dependencies.

The code must handle JSON round-trips (including Unicode and nested data), transaction rollback after errors, lease expiry/retries with fencing, dependency cycles and transitive terminal propagation, deterministic ordering, reopen durability, at least eight concurrent threads, and concurrent claims from independent processes. Avoid transaction leaks after read-only or failed operations. Do not import third-party libraries, access a network, or invoke external commands.
